# 🌸 AI Flower Name Detection

An AI-powered Flower Name Detection system that uses Computer Vision and Deep Learning techniques to identify flowers from images and videos.

## 🚀 Features

* 🌺 Flower detection from images
* 🎥 Flower detection from videos
* 🔍 Deep search and flower analysis
* 🖼️ Image processing and result generation
* 🎬 Video frame and scene processing
* 🤖 AI-based computer vision detection
* 🌐 Flask-based application interface
* 📊 Detection result visualization

## 🛠️ Tech Stack

* **Python**
* **OpenCV**
* **Computer Vision**
* **Deep Learning**
* **Flask**
* **Image Processing**
* **Video Processing**

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/swapnilpatil2414/AI-Flower-Name-detection.git
```

Go to the project folder:

```bash
cd AI-Flower-Name-detection
```

Install the required Python packages:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Run the Flask application:

```bash
python app.py
```

Then open the local URL shown in the terminal.

## 🧪 Testing

The project contains different scripts for testing flower detection, image processing, video processing and scene analysis.

Example:

